# Jeevika Edu Academy — Product Plan

## Goal
Create a premium, simple-to-use digital companion for Jeevika Edu Academy students.

## Primary screens
1. Home
2. Courses
3. Course details
4. Quiz of the Day
5. Resources
6. Notices
7. Contact

## Design direction
- Light, clean academic interface
- Jeevika navy blue with warm amber/gold accents
- Large readable typography
- Mobile-first responsive layout
- Preserve the supplied logo exactly

## Suggested stack
- Web: Next.js + TypeScript
- UI: Tailwind CSS
- Backend: Node.js/API routes
- Database: PostgreSQL
- Authentication: OTP/email provider
- Storage: object storage for PDFs and videos
